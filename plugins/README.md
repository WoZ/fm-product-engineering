# Plugins

This directory holds distributable plugins. No plugins exist yet.

Each future plugin belongs in its own `fm-<descriptive-name>` directory. Skills belong to their plugin, with names unique across this monorepo and without the `fm-` prefix. Names such as `fm-research-and-analysis`, `fm-decision-records`, and `rfd-brief-creation` are illustrative, not reserved or implemented packages.

Before creating the first plugin, read [Naming](../repository-governance/conventions/naming.md), [Repository layout](../repository-governance/conventions/repository-layout.md), [Skill authoring](../repository-governance/conventions/skill-authoring.md), and [Agent compatibility](../repository-governance/conventions/agent-compatibility.md).

That milestone introduces a usable package and its Codex installation checks. A marketplace catalog is deferred until then. Optional resources and integrations are added only when a package needs them.
